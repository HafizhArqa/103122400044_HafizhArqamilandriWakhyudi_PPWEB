# ONE 'O ONES Store - React Frontend

Frontend aplikasi katalog produk merchandise dan musik artis ONE 'O ONES untuk Tugas Bab 6 React Dasar.

## Scripts

- `npm run dev` - Menjalankan dev server di `http://localhost:5173`
- `npm run build` - Membangun bundle produksi
- `npm run preview` - Preview bundle produksi lokal
