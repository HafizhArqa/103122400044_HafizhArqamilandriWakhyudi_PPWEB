    Inti Materi dan Petunjuk Pengujian

    Halaman ini menerapkan dua teknik AJAX sekaligus untuk membuktikan sifat asynchronous dalam aplikasi web:

    1. XMLHttpRequest (XHR): Mengambil berkas statis pengumuman.txt secara asinkron dengan memeriksa readyState === 4 dan status HTTP 200–299.
    2. Fetch API: Mengambil data JSON pengguna dengan memeriksa response.ok, memotong maksimal 3 pengguna pertama, dan menampilkan nama sumber beserta jumlah data.
    3. Non-blocking UI: Saat request pengumuman atau peserta sedang berjalan (status loading), praktikan dapat terus mengetik catatan atau mengklik tombol Tambah hitungan. Nilai catatan, angka hitungan, dan waktu awal tidak pernah hilang karena seluruh proses berjalan tanpa memuat ulang (reload) halaman.

    Skenario Pengujian Soal 1

    • Uji Pengumuman: Klik tombol Muat pengumuman. Ubah isi pengumuman.txt lalu klik lagi; isi baru langsung tampil.
    • Uji Error 404: Ubah sementara target request di app.js menjadi hilang.txt; status HTTP 404 akan ditampilkan secara informatif.
    • Uji Asynchronous: Klik Ambil peserta (Mock lokal dijeda 1,5 detik). Selama loading, ketik di kolom catatan dan klik Tambah hitungan 3 kali. Catatan, angka 3, dan waktu awal tetap utuh saat 3 pengguna muncul.
    • Uji API Eksternal: Pilih JSONPlaceholder lalu klik Ambil peserta. Maksimal 3 pengguna eksternal akan tampil atau muncul panduan jika jaringan terputus. Pilihan sumber tidak berganti otomatis.
