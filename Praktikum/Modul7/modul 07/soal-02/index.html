Aplikasi Registrasi Peserta React

Menggunakan Axios (GET & POST), useState, useEffect, pengelolaan kondisi loading/error/timeout, pembersihan effect (cleanup AbortController), serta validasi formulir di React.

Inti Materi dan Petunjuk Pengujian

Aplikasi React ini menggabungkan manajemen state terpusat dengan konsumsi API melalui library Axios:

  1. useEffect & AbortController: GET daftar peserta dipicu otomatis saat mount dan saat pilihan skenario berubah. Cleanup effect membatalkan request yang sedang berjalan dan mencegah response kadaluwarsa menimpa state terbaru.
  2. Axios GET & 4 Skenario:
    • Berhasil: delay 1000 ms, timeout 5000 ms.
    • Data kosong: mode=empty, delay 1000 ms, timeout 5000 ms.
    • Error HTTP: mode=error (HTTP 503), delay 1000 ms, timeout 5000 ms.
    • Timeout: delay 2500 ms dengan timeout Axios 700 ms, memicu ECONNABORTED sebelum server selesai merespons.
  3. Axios POST & Validasi: Formulir pendaftaran memvalidasi input nama (tidak boleh kosong/spasi) dan format email dengan regex sebelum mengirim JSON. Respons 201 dengan atribut simulated: true ditampilkan terpisah tanpa mengubah daftar GET.

Skenario Pengujian Soal 2

  • Uji Muat Ulang: Buka halaman, lalu klik tombol Muat ulang. Request baru dipicu tanpa reload halaman.
  • Uji Data Kosong & Error HTTP: Ganti skenario ke Data kosong lalu Error HTTP. Daftar lama segera dibersihkan dan status menampilkan pesan sesuai respons.
  • Uji Timeout: Pilih skenario Timeout. Request dibatalkan setelah 700 ms (sebelum jeda 2500 ms). Setelah itu, pilih kembali Berhasil untuk memastikan aplikasi pulih.
  • Uji Pergantian Cepat: Ganti pilihan secara cepat saat status masih loading; request sebelumnya dibatalkan oleh cleanup effect dan hanya response terbaru yang ditampilkan.
  • Uji Kirim Valid: Masukkan nama Rina Praktikan dan email rina@example.com lalu kirim. Status HTTP 201, ID 101, data sesuai input, dan simulated: true muncul, sementara daftar GET tetap utuh.
  • Uji Validasi: Coba kirim nama yang hanya berisi spasi atau email tanpa format valid; formulir menolak pengiriman dan menampilkan petunjuk perbaikan.
